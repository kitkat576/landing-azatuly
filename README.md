# landing-azatuly
# Лендинг кофейни «Алматы Кофе»

**Тема:** Кофейня в Алматы (меню, атмосфера, бронирование столиков).  
**Живой сайт:** https://azatuly.github.io/landing-azatuly/

## Что реализовано:
- **Семантическая разметка HTML5:** `header`, `nav`, `main`, `section`, `article`, `footer`.
- **Иерархия заголовков:** строго соблюдена структура `h1` → `h2` → `h3`.
- **Разделы:**
  - Шапка с навигацией.
  - Блок «О нас».
  - Меню с изображениями (`alt` указаны).
  - Преимущества и атмосфера.
  - Форма бронирования (связана через `<label for="...">`, обязательные поля `required`).
- **SEO и мета-данные:** `meta viewport`, `meta description`, `title`, подключен `favicon`.
- **Адаптивность:** отзывчивый интерфейс на чистом CSS (Media Queries) для мобильных устройств (от 375px) и десктопов (1280px+).
